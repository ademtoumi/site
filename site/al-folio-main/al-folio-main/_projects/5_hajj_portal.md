Trilingual (Arabic, English, French) web platform for Hajj pilgrimage management with full RTL/LTR layout switching.

## Features

- **User application:** Pilgrim registration, hotel reservations, lottery draws, journey tracking.
- **Admin dashboard:** Real-time updates via Socket.io, comprehensive reservation management.
- **Internationalization:** Complete Arabic RTL support, English, and French.
- **State management:** TanStack Query for efficient server state synchronization.
- **Validation:** Zod schemas with React Hook Form for type-safe form handling.
