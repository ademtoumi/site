Designed and developed a production-ready Retrieval-Augmented Generation (RAG) platform for intelligent document understanding and question answering. The system combines Hybrid Retrieval (FAISS + BM25), Cross-Encoder Reranking, Explainable AI (XAI), Google Gemini LLM, and a modern React interface to deliver accurate, transparent, and context-aware responses.

## Key Features

- **Retrieval-Augmented Generation (RAG):** End-to-end architecture coupling dense vector retrieval with Google Gemini LLM synthesis.
- **Hybrid Search:** Fuses FAISS vector embeddings with BM25 keyword matching for optimal recall across technical documents.
- **Cross-Encoder Reranking:** Re-scores retrieved candidate chunks using deep cross-encoders to ensure top relevance.
- **Explainable AI (XAI):** Provides transparent source attribution, confidence scores, and chunk citation highlights.
- **Production Infrastructure:** RESTful FastAPI backend, modern React + Vite dashboard, React Query state management, and containerized Docker deployment.
