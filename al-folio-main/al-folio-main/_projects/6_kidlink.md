Cross-platform Flutter mobile application for structured parent-teacher communication in primary schools.

## Features

- **Role-based interfaces:** Distinct flows for parents, teachers, and school administrators.
- **Real-time messaging:** Firebase Cloud Messaging (FCM) push notifications.
- **Authentication:** Firebase Auth with role-based access control.
- **State management:** Provider pattern for scalable app state.
- **Data storage:** Firestore real-time database with offline support.
